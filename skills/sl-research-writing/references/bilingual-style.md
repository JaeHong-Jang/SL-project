# Bilingual Style

## Terminology

- Keep key terms consistent across Korean and English drafts.
- Define a Korean term with its English equivalent on first use when both audiences matter.
- Do not alternate translations for the same concept unless a discipline-specific distinction exists.

## Place Names

- Use official romanization for Seoul place names when available.
- Keep administrative unit names consistent between maps, tables, and prose.
- Avoid translating proper nouns unless an accepted English name exists.

## Tone

- Korean prose may use slightly longer connective phrasing, but keep analytical claims direct.
- English prose should favor compact sentences and explicit subject-verb structure.
- For slides, use parallel noun phrases across languages where possible.
