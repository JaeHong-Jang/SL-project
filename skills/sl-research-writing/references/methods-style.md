# Methods Style

## Voice

- Use past tense for completed processing and analysis.
- Use active voice when naming analytical choices.
- Keep software details concise unless they affect reproducibility.

## Structure

1. Describe study area and unit of analysis.
2. Describe input datasets and key variables.
3. Explain cleaning, geocoding, CRS, and joins.
4. Define the accessibility metric.
5. Summarize validation and sensitivity checks.

## Precision

- State thresholds, weights, and aggregation rules.
- Report exclusions and missing data handling.
- Avoid vague verbs such as considered, reflected, or analyzed when a specific operation can be named.
