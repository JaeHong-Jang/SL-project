# Project Argument

## Core Claim Shape

Frame the project around spatial mismatch between service need and service availability. The strongest argument connects observed access gaps to measurable geography rather than broad statements about inequality.

## Contribution

- Define what the project measures that was previously unclear.
- Explain why the chosen spatial unit and accessibility measure are appropriate.
- Connect findings to planning or service delivery decisions without overstating causality.

## Interpretation

- Separate descriptive findings from normative recommendations.
- Use map patterns as evidence only when backed by the underlying data.
- Name limitations that affect interpretation, such as data age, service capacity, or travel-mode assumptions.
