# QGIS 레이어 규칙

## 이름 규칙

- `raw_`: 원본 또는 원본 복사본
- `wrk_`: 처리 중간 산출물
- `qa_`: 오류, 검수, 의심 후보
- `out_`: 최종 분석 산출물
- `map_`: 지도 레이아웃 또는 export 산출물

파일명은 가능하면 영어 식별자를 쓰고, 지도에 표시되는 이름은 필요할 때 한국어로 바꾼다.

## 그룹 규칙

QGIS 레이어 패널은 다음 그룹을 기본으로 둔다.

```text
00_raw
01_reference
02_working
03_QA
04_outputs
05_maps
```

원본 레이어는 `00_raw`에 두고 직접 편집하지 않는다. 임시 처리 결과는 분석에 쓰기 전에 반드시 GeoPackage로 저장한다.

## 스타일 규칙

- 원본 레이어: 회색 계열, 낮은 opacity
- 작업 레이어: 파란색/청록색 계열
- QA 레이어: 빨강/주황 계열
- 최종 결과: colorblind-safe sequential 또는 diverging ramp
- 분석 제외/NoData: 밝은 회색 hatch
- 정류장/출입구/엘리베이터: 작고 어두운 점

## 비교 지도 규칙

비교 지도는 class break를 고정한다. 특히 `S0-M3` 기준 취약도와 시나리오 개선효과 지도는 자동분류를 매번 새로 하면 안 된다.
